# 更新日志

记录 Steam Account Manager 各版本面向用户的变更，与本地安装包、便携版放在同一目录。

## 0.11.11 安装版检测并引导安装 WebView2

- NSIS 安装版在复制文件前检测 Microsoft Edge WebView2 Runtime；缺失时提示并从 `cdn.qrqto.club` 下载独立安装包。
- 用户取消、下载失败或安装后仍检测不到 Runtime 时中止安装，并打开 CDN 下载链接。
- 便携版不检测、不提示；需本机已有 WebView2。
- 关闭 Tauri 默认向 Microsoft 静默拉取引导程序，避免国内失败且无提示。

## 0.11.10 CFG 源码编辑与当前指令注释

- CFG 工作台改为直接编辑文件，去掉可视化分区、滑块和准星预览。
- 按当前 CS2 指令库维护行尾注释：补上 telemetry、语音音量和持枪左右手等新指令，并标明 net_graph、voice_scale 等已失效项。
- 新建方案和空的默认 autoexec 会填入带注释的当前模板；「刷新注释」只更新说明，不改命令值。

## 0.11.9 软件包持续检查更新

- 应用运行中每 6 小时再静默检查一次 CDN 新版本，发现后仍只在左下角亮「更新」。
- CDN 定时从官方源刷新 Steam 与 TeamSpeak 安装包，并发布 `packages.json` 版本清单。
- 平台页对比本机版本与 CDN 清单，过期时显示「有新版本」并可直接下载更新。

## 0.11.8 列表开关、静默扫描与 CDN 更新

- 「只切 Steam」改为账号列表顶端的固定文案开关：点开、再点关，窄窗口也不再藏成图标。
- 启动扫描改为后台进行：先显示本机账号，头像和头像框随后补齐；扫描时仍可筛选、拖拽和切号。
- 左侧栏底部直接显示当前版本和更新按钮。点更新后下载、安装并自动重启，不再弹出额外选项。
- Steam、TeamSpeak 3 客户端/服务端安装包和应用更新改为从 `https://cdn.qrqto.club` 下载，不再依赖 GitHub。

## 0.11.7 只切 Steam 与打包清理

- 账号页增加「只切 Steam」开关，默认打开：打开时只切换 Steam；关闭时在 Steam 就绪后启动该账号已关联且本机已配置的 5E 和完美平台。
- 切换确认框按当前开关和实际关联说明将执行的步骤，不再写死“关联 5E 就一定启动 5E”。
- 去掉侧栏和设置页上的“不保存密码 / Token / Cookie”承诺文案。
- 本地打包在产物复制到 `release/` 并校验后删除 `src-tauri/target` 和 `dist`，避免构建中间文件占盘。

## 0.11.6 Steam 登录就绪后启动 5E

- 切换已关联 5E 的账号时，读取 Steam 本机 `ActiveUser` 并与目标 SteamID64 精确匹配，连续稳定后才启动或重启 5E。
- Steam 未提供有效活动用户信号时最多等待 10 秒后兼容启动；若明确检测到其他账号，则保留 Steam 切换结果并阻止 5E 启动。
- 切换弹窗实时显示关闭 Steam、准备 CFG、等待登录、等待服务和启动 5E 等阶段，等待期间禁止重复操作。

## 0.11.5 扫描体验与头像框刷新

- 修复账号首页拖拽顺序因设置白名单遗漏而无法保存的问题。
- 启动、手动与定时扫描共享同一个任务；已有账号立即显示，扫描按钮提供旋转状态且不会重复发起扫描。
- 头像与头像框资源增加缓存版本，增强 Steam 页面解析，并在网络或页面结构异常时保留已有媒体以便后续重试。

## 0.11.4 Steam 头像框与可靠拖拽

- 启动后从公开 Steam 社区资料同步动态头像与头像框到应用缓存；头像和头像框均保留原始 GIF、WebP、APNG 或 PNG 内容，列表与详情视图统一展示。
- 账号页和平台页不再依赖 Tauri WebView 中不稳定的原生 HTML5 拖拽，改用 Pointer Events；拖动仅由把手触发，释放后持久化新顺序。
- 手动“重新扫描”会强制刷新 Steam 社区头像资料；自动扫描保持轻量，不会每 10 秒访问网络。

## 0.11.3 动态头像与平台资源修正

- Steam 本地头像缓存支持 GIF、动态 WebP 和 APNG 原始文件，动画帧不会被转换或压平；缓存上限提高到 8 MB。
- 平台页使用 Steam 官方图标，不再复用 Steam Account Manager 应用图标。
- Steam 与其他平台的 Windows 路径统一使用大写盘符和反斜杠展示，手动选择的新路径也按相同格式保存。

## 0.11.2 平台与设置布局统一

- 平台页统一管理 Steam、5E、完美世界竞技平台和 TeamSpeak 3，默认按此顺序显示；每个平台均通过独立拖拽把手调整位置并持久保存。
- Steam 安装目录从设置页移至平台页；设置页将版本和更新信息前置，将软件数据与 Steam 切换配置恢复合并到同一备份板块，5E 与完美查询 Token 默认折叠并置底。
- 账号首页每 10 秒静默重新扫描本机 Steam 账号；手动扫描仍保留明确反馈。账号与平台排序均只允许从把手开始拖拽，避免整行拖动时出现禁用光标。

## 0.11.1 平台保存状态与选择性恢复

- 平台资料点击保存后立即结束编辑；平台查询失败不再阻止关闭，已保存但查询异常的平台卡片使用红色状态提示。
- 软件备份仍为全量明文 JSON；恢复时可分别勾选账号与平台资料、CFG 方案与分配、软件设置与平台程序。
- 账号恢复按 SteamID64 与本机当前可用 Steam 账号匹配，只导入匹配账号的别名、标签、平台昵称、登录账号、明文密码和备注，未匹配记录直接忽略。

## 0.11.0 自定义账号顺序与平台卡片

- 账号列表只保留 Steam 头像和 Steam 昵称作为主身份；完美、5E 固定为短卡片，未填写时使用灰色空状态，填写后高亮并仅显示平台用户名，长名称自动省略。
- 无搜索、标签、收藏或平台筛选时，可拖拽整条 Steam 账号调整全局顺序，也可在拖拽手柄上使用 `Alt + ↑/↓`；顺序保存在普通应用设置并随软件备份导出。
- 仅筛选 5E 时展示竞技分数，默认从低到高。未定级账号排在已定级账号之前，组内用上赛季分数排序；没有上赛季分数时作为最低值，参考分不在列表展示。
- 点击完美或 5E 卡片打开独立平台资料编辑弹窗。详情抽屉只读展示平台账号卡片，展开后显示账号、遮罩密码、备注，并按需加载详细战绩。

## 0.10.2 账号列表与 5E 定级排序

- 账号列表重新按 Steam 身份、辅助资料、平台竞技状态和操作排版；未填写平台不再显示“待填写”，已关联平台使用更小的高亮词条。
- 筛选 5E 后可按有效分数升降序或最近切换排序。已定级账号使用本季 ELO，定级账号显示已打场次并使用上赛季最终分数参与排序，无参考分时排在末尾。
- 5E 定级状态优先读取比赛摘要的 `match_status`、`origin_match_total` 与天梯类型，排除 1v1 等非天梯模式，避免把定级临时分或上赛季旧分显示为当前 ELO。

## 0.10.1 平台快捷资料与文件备份

- 每条 Steam 账号固定显示完美平台和 5E 快捷入口，未配置时显示“待填写”；点击后直接在详情中编辑对应平台。
- 完美平台和 5E 可分别保存平台昵称、登录账号、明文密码和备注；账号与密码支持复制，密码默认遮罩，5E 使用平台昵称查询玩家数据。
- 软件资料改为导出、选择明文 JSON 备份文件；恢复前在应用数据目录静默保存当前资料，再以数据库事务整体替换。查询 Token、玩家缓存、切换日志和 Steam 登录凭据不进入备份。

## 0.9.0 5E 切号联动与界面精简

- CFG 参数库导入、导出和添加命令提升到编辑器全局标签栏；分区标题只保留当前分区名称，窄窗口自动收起次要文字。
- 账号列表用“平台 · 段位 · 分数”紧凑展示缓存数据，平台页不再重复汇总账号关联；“本地确认”优先显示 Steam 中文昵称。

- 设置页为 5E 和完美平台查询凭据提供第一方官网入口及获取步骤，同时明确两家平台均没有公开 API 凭据申请页。

## 0.8.0 CFG 工作台精简

- CFG 页面将编辑方式、自动保存和安全边界合并为全局说明，方案选择、重命名、删除、导入、新建、导出与保存状态集中在顶部工具栏。
- 编辑器标签栏只保留“可视化配置”和“CFG 源码”，不再重复显示方案名称与文件名；分区标题栏同步压缩，释放更多编辑空间。
- 移除历史版本和 CS2 运行文件只读预览，不再创建 CFG 历史快照；已有数据库历史表和旧数据原样保留以兼容升级。

## 0.7.1 平台检测与切号行为修复

- 5E 与 TeamSpeak 3 的自动检测覆盖常见安装目录和 Windows 卸载注册表信息；完美世界、5E 与 TeamSpeak 3 自动检测失败时仍可手动选择启动程序。

- 切换账号时仍会在本机已安装 CS2 的情况下同步并校验所选 CFG，但完成后只按目标账号重新启动 Steam，不再自动启动 CS2 或任何关联平台。

## 0.7.0 平台数据更新时间

- 5E 与完美平台玩家数据面板底部显示“平台数据更新于 N 分钟前”，使用缓存快照的 `fetchedAt` 计算，并在面板打开期间每分钟自动更新。
- 鼠标悬停更新时间可查看本地格式的完整时间；该显示不会额外请求平台接口。

## 0.6.7 CFG 参数库与窄窗口布局

- 可视化工作台支持导入和导出 JSONC 参数库，用于维护参数解释、所属分区、开关/数字/选项/文本控件，以及数字滑块的最小值、最大值和步长。
- 导出的参数库文件开头包含可直接交给 GPT 的维护提示词；导入时会校验结构、重复命令、控件类型、选项和数值范围，验证通过后持久保存到本地设置。
- 窄窗口不再过早把准星检查面板扩展成整行大区域；中等宽度保持紧凑三栏，更小窗口使用横向分区标签和双列紧凑预览。

## 0.6.6 CFG 可视化工作台

- CFG 工作台默认使用“可视化配置”，并保留“CFG 源码”和 500ms 自动保存；两种视图共享同一份草稿。
- 无损解析会保留 BOM、CRLF、注释、空行、命令顺序、引号、分号命令链和未知命令。可视化修改只更新目标命令；重复标量按最后一条生效并提示覆盖项。
- 配置按准星、声音与语音、绑键、鼠标与操作、HUD/雷达与持枪视角、性能与网络、脚本与别名、练习/服务器和其他命令分区。
- 准星支持高 DPI Canvas 近似预览、深浅/场景背景、CFG 命令复制；只有参数完整且有效时才会生成官方 `CSGO-xxxxx` 分享码。
- 当前方案可通过 Windows 保存对话框导出为 UTF-8 `.cfg` 文件；无扩展名会自动补全，其他扩展名会被拒绝。导出不修改 CS2 实时文件，也不会启动游戏。

## 0.6.5 5E 战绩后台定时刷新

- 应用启动后自动刷新所有已填写玩家名称、主页 ID 或链接的 5E 关联，之后每 15 分钟批量刷新一次。
- 打开账号详情默认直接读取最近缓存，不再因缓存到期同步等待 5E 网络查询；手动刷新仍可强制立即查询。
- 本地打包会将旧安装包、便携版和历史目录移入 `release/history/`，`release/` 根目录只保留最新构建产物。

- 明确区分 5E 名称查询与完美平台 SteamID64 自动匹配，说明两者当前可展示的数据边界。

## 0.6.3 完美平台 SteamID 自动匹配

- 配置完美平台 Access Token 后，账号详情会直接使用现有 SteamID64 自动建立或补全完美平台关联，无需填写额外平台 ID。
- 账号主页的平台徽标显示已缓存的 5E / 完美段位和分数；完美分数明确标注为“赛季记录分数”，不冒充实时官方值。
- 5E 与完美凭据分别存入 Windows 凭据管理器；完美未配置 Token 时不发起平台请求，并保留普通平台关联能力。

## 0.6.2 5E 名称查询与平台关联编辑

- 5E 玩家查询支持唯一玩家名称、主页 ID和完整主页链接；名称只接受完全匹配或唯一的大小写不敏感匹配，不采用模糊结果。
- 平台账号信息改为可选，只选择平台即可建立普通关联；仅在 5E 关联包含玩家信息时查询战绩。
- 已有关联可以载入原表单编辑；更换玩家、清空玩家信息或切换平台时自动清除旧战绩缓存。

## 0.6.1 5E 玩家数据查询

- 账号详情可验证 5E 玩家名称、主页 ID或完整主页链接，并查询身份、段位、最近比赛后 ELO、KD、Rating、ADR、爆头率、胜率及最近 20 场比赛。
- 后端通过统一玩家查询接口适配 5E 网页数据服务；单场详情失败会保留其余结果，成功快照缓存 15 分钟，离线时可回退到过期缓存。
- 可选 Bearer Token 只存入 Windows 凭据管理器，不进入 SQLite、日志或导入导出；Token 失效时自动降级为匿名查询。

## 0.2.0 Steam 官方登录新增与账号详情

- 账号列表只展示 Steam 已记住的账号。无凭证账号会隐藏，但别名、备注、标签、平台关联和头像缓存继续保留。
- 账号详情与编辑合并为右侧抽屉，登录账号名仅在详情显示，SteamID64 不再进入界面。
- 标签支持多选快速筛选，账号必须同时满足全部已选标签。
- 移除手工 SteamID64 新增、不可用账号清理入口和账号标识色；导入只能更新已扫描过的账号。

## 0.1.2 账号资料与主题升级

- 从 Steam 本地 `config/avatarcache` 同步 PNG/JPEG 头像到应用专属缓存；源头像暂时缺失时保留最后一次缓存，不调用远程 API。
- 日常列表隐藏 Steam ID，以头像、昵称、是否在 Steam 登录列表、平台关联和标签为核心；Steam ID 仅保留在编辑资料的“高级信息”中。
- 使用完美世界、5E、FACEIT、其他和未关联作为平台筛选；旧手工分组仅为导入兼容保留，不再显示。
- 历史标签支持搜索、多选和按 Enter 新建；账号标识色限定为天蓝、青色、紫色、薄荷、珊瑚和琥珀。
- 提供极光蓝、脉冲紫、薄荷青和冰川白四套高对比主题，并在启动前恢复上次主题，避免闪烁。
- “未在 Steam 登录列表”的资料可单独或批量移除；清理只删除本应用中的别名、备注、标签关联、平台关联和头像缓存，不修改 Steam 文件。

头像缓存位于应用数据目录的 `avatars\`。WebView 的本地资源权限只允许访问这个目录，不允许直接读取 Steam 配置目录。
